# awesome-life-automation

Herramientas open source para que tu agente personal (Claude Code, Codex, Cursor…) haga tus recados en España: la compra, la cita en la peluquería, la factura del móvil o el tren del viernes.

El objetivo es que tu agente tenga a mano un catálogo de herramientas que pueda usar por ti: CLIs, servidores MCP, skills, bots e integraciones de Home Assistant que trabajan con **tu propia cuenta** o te avisan cuando pasa algo que te importa.
